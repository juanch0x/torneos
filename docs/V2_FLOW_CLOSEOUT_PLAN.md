`src/domain/v2Membership.ts` now exempts only genuinely absent optional duration/calendar
metadata from the display diagnostic gate. It does not treat supplied invalid duration or
calendar data as valid. Structural/reference/membership diagnostics and semantic pairing
checks remain active; scheduled matches, assigned slots and group/playoff history remain
protected. Generation and restrictions still require their existing configuration gates.

- **RED:** two new real-factory domain regressions failed (`assigned.ok` / absent-calendar
  assignment expected `true`, received `false`) before the eligibility fix.
- **GREEN:** fresh `createTournament` assignment/movement, absent calendar, semantic
  survivor identity, malformed provided config, duplicate identities/membership and invalid
  references pass. Malformed `fixtureSettings` containers (null/string/array) are also rejected;
  their preservation regression observed an incorrect acceptance before the narrow
  container-aware missing-duration check. Independent review additionally found that
  arrays passed the object check: domain and durable controller regressions first failed,
  then passed after an explicit `Array.isArray` exclusion, proving rejection/no mutation
  and **zero repository writes** for `[]` and `['garbage']`. No source mutation is introduced.
- Durable controller coverage now includes a factory capture without duration/calendar,
  one save per accepted action, fresh-session readback, IDs/windows/opaque pair preservation,
  unchanged input, configuration-gated generation and exact uncertain document/index retry.
- Existing stale epoch, pending duplicate submit, source switch and durable retry tests remain.

### XLSX: local civil values in actual serialized cells

`src/export/xlsxWriter.ts` projects local civil components into Date coordinates only for
planning cells before the installed writer converts them to Excel serials. The projection
is presentation-only: it does not replace any source timestamp. Legacy fixture cells
continue using their original UTC serial semantics.

- **RED:** three actual-byte Mendoza regressions failed by **0.125 days / three hours**:
  09:00 with milliseconds, a previous-day local rollover and a next-day source-offset
  rollover. UTC control passed before the production fix.
- **GREEN:** `planningSerialization.test.ts` serializes with the installed writer's supported
  `toBuffer()` API, decodes ZIP worksheet numbers and styles with its existing ZIP dependency,
  and checks Mendoza/UTC date-time serials plus `dd/mm/yyyy` / `hh:mm` number formats.
- The same tests verify exact raw ISO strings, confirmed source version and browser-resolved
  timezone metadata; source immutability, no results/standings and legacy serialized serials
  are preserved. Missing match-number safety remains covered by planning projection tests.
- Runtime `Intl` can resolve the equivalent Mendoza timezone alias as `America/Mendoza`;
  assertions verify the resolved equivalent name rather than assuming the input alias.
